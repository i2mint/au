au.http.mk_http_interface(functions=None, backend=None, store=None, title='AU Task API', description='Async task management API', version='0.1.0')[source]#

Create a FastAPI application for task management.

Parameters:

  • functions (Optional[list[Callable]]) – Optional list of functions to register

  • backend (Optional[ComputationBackend]) – Optional backend for task execution

  • store (Optional[ComputationStore]) – Optional store for results

  • title (str) – API title

  • description (str) – API description

  • version (str) – API version

Return type:

FastAPI

Returns:

FastAPI application instance

Raises:

ImportError – If FastAPI is not installed

Example

>>> @async_compute
>>> def my_func(n: int) -> int:
>>>     return n * 2
>>>
>>> app = mk_http_interface([my_func])
>>> # Run with: uvicorn main:app --reload
