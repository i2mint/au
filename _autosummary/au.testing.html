launch(func, args, kwargs, key, store=None)[source]#

Execute function synchronously and store result immediately.

Runs the body every au worker runs, so it records results as they do: result.error is the exception itself, and a BaseException is recorded FAILED, then re-raised to the caller.

au.testing.mock_async(backend=None, *, store=None)[source]#

Run every task launched inside the block on a synchronous test backend.

It becomes the default backend of au.async_compute() and of the simple API (au.submit_task, …). The simple API’s results go to store (a fresh InMemoryStore by default), which is restored on exit: read them inside the block, or pass a store you keep.

Usage:

with mock_async() as mock:
    @async_compute
    def my_func(n: int) -> int:
        return n * 2

    handle = my_func(5)
    assert mock.task_count == 1
    assert handle.get_result() == 10
Parameters:

  • backend (Optional[ComputationBackend]) – Optional custom backend (defaults to TrackingTestBackend)

  • store (Optional[ComputationStore]) – The simple API’s store inside the block (default: in memory)

Yields:

MockTaskTracker instance
